# KonyaGo Arşiv

Canlı site: **https://konyagoarsiv.org**

Konya odaklı topluluk — forum, ikinci el ilan panosu, iş panosu.

## Geliştirme

```bash
npm install
npm run dev
npm run build
npm run build:pages   # GitHub Pages statik çıktı → pages-dist/
```

`main` dalına push → GitHub Actions Pages deploy.
